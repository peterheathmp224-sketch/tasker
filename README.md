# Tasker — Telegram Mini App (Vanilla JS + FastAPI + Postgres, без Node)

## Запуск (локально, Node не нужен)
1. Подними Postgres: `docker compose up -d db`
2. Бэкенд + фронт (фронт — статика `web/`, отдаёт сам FastAPI):
```
cd backend
copy .env.example .env   # впиши BOT_TOKEN; DATABASE_URL уже на Postgres
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```
3. Открой `http://localhost:8000/` — это и есть приложение (в браузере работает с мок-юзером, DEV_MOCK_USER=true).
4. Для Telegram: `ngrok http 8000` → https-URL в `WEBAPP_URL` → `python bot/setup_menu.py` → открыть через кнопку Menu бота.

## Вход через Telegram в браузере
- В Mini App авторизация идёт через `initData` автоматически.
- В обычном браузере показывается кнопка «Войти через Telegram» (Login Widget).
  Нужны `BOT_USERNAME` в `.env` и привязка домена в BotFather (`/setdomain`).
  После входа бэкенд выдаёт сессионный токен (HMAC, 30 суток, хранится в `localStorage`).
  Секрет подписи — `SESSION_SECRET`, если пусто — используется `BOT_TOKEN`.
- Без Telegram и без сессии API отвечает `401` и никого в БД не создаёт
  (мок-юзер — только при `DEV_MOCK_USER=true`).

## Правила v1
- Дедлайн — только дата. Календарь группирует по дате, табы Мои/Группа/Все.
- Статусы: new / in_progress / done.
- Редактировать/удалять может любой.
- Удаление группы отвязывает задачи (group_id=NULL), задачи не удаляются.

## Уведомления через бота
- Бэкенд шлёт сообщения через Bot API (нужен `BOT_TOKEN`) best-effort фоном,
  на скорость API не влияет. Себе уведомления не приходят.
- События: новая задача (исполнителям + группе), смена статуса, назначение/снятие,
  привязка/отвязка группы, новый срок, удаление задачи, удаление группы,
  добавление/исключение из группы, прикрепление файла.
- Если юзер заблокировал бота (403) или ни разу его не запускал (400) —
  отправка тихо пропускается, API при этом не падает.
